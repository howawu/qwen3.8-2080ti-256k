# Pelican bicycle creative coding test

Prompt:

> Create an animated SVG of a pelican riding a bicycle.

The local model produced the SVG animation implementation, including inverse-kinematics pedaling, rotating wheels/crank and a scrolling background. The GIF below is a rendered result of that generated code: 600×338, 48 frames, 2.4 seconds at 20 fps.

![Pelican riding a bicycle](pelican-bike.gif)

This is a creative coding example, not proof that the model generated pixels directly. It demonstrates instruction following and production of a working animated SVG pipeline.
